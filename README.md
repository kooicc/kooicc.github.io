# BI4BOB 业余无线电台 QSL 查询系统

这是一个用于展示和查询个人业余无线电通联（QSO）日志的轻量级网页项目。

网站采用现代科技风设计，每日自动同步必应壁纸，配合毛玻璃质感的半透明表格和藏青色主标题，为访客提供一个快速、清晰且优雅的通联记录查询体验。

## ✨ 主要功能

- 📻 通联日志展示：清晰呈现每次通联的时间、呼号、频率、模式、信号、位置及 QSL 收发状态。
- 🔍 全字段搜索：支持输入呼号、频率、位置等任意关键字进行实时过滤查询。
- 🎛️ QSL 状态过滤：支持按“全部、已寄出、已收到、未收到”等状态一键筛选日志。
- 🖼️ QSL 卡片墙：点击“QSL”标签，可展示所有通过图床托管的 QSL 卡片电子版。
- 🔗 一键查询 QRZ：点击表格中的呼号，自动在新标签页打开 QRZ.com 对应的个人主页。
- 📄 分页与折叠：默认折叠以保持壁纸美观；支持点击展开及使用 Esc 快捷键快速清空搜索。
- 🖼️ 每日必应壁纸：背景自动拉取每日更新的必应美图，每天打开都有新鲜感。
- 📱 全端自适应：完美适配电脑与手机端，手机端表格支持横向滑动，排版精致不拥挤。

## 📊 如何添加通联记录？

为了让数据更易维护，通联数据已经独立存放在 qso_data.json 文件中。

数据格式要求（JSON 数组）：
["通联时间", "呼号", "频率(MHz)", "模式", "信号(RST)", "位置(QTH)", "QSL收到时间", "QSL寄出时间"]

例如：
["2026-10-25 14:30", "JA1ABC", "14.074", "FT8", "-10", "日本-东京", "2026-10-28", "2026-10-26"]

注：如果 QSL 还没收到或还没寄出，请使用空字符串 "" 表示，系统会自动显示为空。代码内置了按时间自动倒序排序的功能，你只需将新数据追加到数组末尾即可，无需手动排序。

## 🖼️ 如何添加 QSL 卡片？

如果你扫描了纸质 QSL 卡片并上传到了图床（如 Cloudflare R2），你可以将图片的直链添加到 script.js 中。

在 script.js 顶部找到 qslImages 数组，将你的图片链接按以下格式追加：
const qslImages = [
  "https://img.你的域名.com/BD8ENX.jpg",
  "https://img.你的域名.com/BH4GDY.jpg"
];

## 🚀 部署说明

本项目通过 GitHub Pages 进行托管。

1. 将代码推送至 GitHub 仓库。
2. 在仓库的 Settings -> Pages 中，选择对应的分支（如 main），并保存。
3. 稍等片刻，即可通过分配的域名直接访问。

(注：由于本系统采用 fetch 异步请求本地 qso_data.json 文件，在本地开发测试时，请使用 VS Code 的 Live Server 插件或 Python 本地服务器启动，直接双击打开 index.html 可能因浏览器跨域限制无法加载数据。)
