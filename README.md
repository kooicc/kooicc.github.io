# BI4BOB 业余无线电台 QSL 查询系统

基于 GitHub Pages 和纯前端技术（原生 HTML/CSS/JS）构建的业余无线电台通联日志展示页面。用于记录和展示个人业余无线电的通联（QSO）记录与 QSL 卡片收发状态。

页面采用现代科技风设计，默认接入每日必应壁纸，配合毛玻璃 UI、深蓝描边标题和响应式布局，为访客提供清晰、优雅的查询体验。

## ✨ 功能特性

- 📻 **QSO/QSL 日志展示** - 以清晰的表格形式展示通联时间、呼号、频率、模式、信号报告、位置以及 QSL 卡片寄出/收到状态。
- 🔍 **全字段实时搜索** - 支持按呼号、频率、模式、位置、日期等任意关键字实时过滤，输入即搜。
- 📄 **分页与折叠** - 每页展示 10 条记录，默认折叠以保证壁纸美观，支持点击展开和快捷键（Esc）清空并折叠。
- 🖼️ **每日必应壁纸** - 背景自动拉取每日更新的必应美图，每次打开都有新鲜感。
- 📱 **移动端自适应** - 针对手机屏幕进行了专门的响应式优化，表格支持横向滑动，排版依然精致。
- 🎨 **纯代码 SVG 图标** - 网站 Favicon 使用纯代码绘制的信号塔 SVG，无需额外加载图片，加载极快。

## 🛠️ 技术栈

- **HTML5** - 语义化标签，支持无障碍访问。
- **CSS3** - 每日动态壁纸、毛玻璃（backdrop-filter）、Flex/Grid 布局、媒体查询及动画。
- **JavaScript (ES6+)** - 纯原生无依赖，使用 DocumentFragment 优化 DOM 渲染性能。

## 📊 数据格式与添加记录

### 数据格式

通联数据定义在 script.js 顶部的 qsoLogs 数组中，格式为：
[通联时间, 呼号, 频率(MHz), 模式, 信号(RST), 位置(QTH), QSL寄出时间, QSL收到时间]

如果 QSL 未寄出或未收到，请用空字符串 "" 表示，页面会自动渲染为 /。

### 添加新记录

在 script.js 中找到 qsoLogs 数组，按上述格式追加一行即可：

["2026-10-25 14:30", "JA1ABC", "14.074", "FT8", "-10", "日本-东京", "2026-10-26", ""]

*注意：代码内置了按时间倒序排序（sort）功能，你无需手动将最新记录插在最前面，直接追加在末尾即可。*

## 🚀 部署说明

本项目完全托管于 GitHub Pages。

1. 将代码推送到你的 GitHub 仓库。
2. 在仓库的 Settings -> Pages 中，选择对应的分支（通常是 main 或 master）并保存。
3. 稍等片刻，即可通过分配的域名访问。

## 📻 关于业余无线电

在中国，必须考取相应的业余无线电操作证书（A类、B类或C类），并申请取得电台执照和专属呼号后，方可进行发射操作。
