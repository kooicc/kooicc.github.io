# BI4BOB 业余无线电台 QSL 查询系统

这是一个用于展示和查询个人业余无线电通联（QSO）日志的轻量级网页项目。

网站采用现代科技风设计，每日自动同步必应壁纸，配合毛玻璃质感的半透明表格和藏青色主标题，为访客提供一个快速、清晰且优雅的通联记录查询体验。

## ✨ 主要功能

- 📻 **通联日志展示**：清晰呈现每次通联的时间、呼号、频率、模式、信号、位置及 QSL 收发状态。
- 🔍 **全字段搜索**：支持输入呼号、频率、位置等任意关键字进行实时过滤查询。
- 📄 **分页与折叠**：默认折叠以保持壁纸美观；支持点击展开及使用 `Esc` 快捷键快速清空搜索。
- 🖼️ **每日必应壁纸**：背景自动拉取每日更新的必应美图，每天打开都有新鲜感。
- 📱 **全端自适应**：完美适配电脑与手机端，手机端表格支持横向滑动，排版精致不拥挤。

## 📊 如何添加通联记录？

所有的通联数据都存放在 `script.js` 文件顶部的 `qsoLogs` 数组中。

数据格式要求如下：
`[通联时间, 呼号, 频率(MHz), 模式, 信号(RST), 位置(QTH), QSL寄出时间, QSL收到时间]`

例如：
`["2026-10-25 14:30", "JA1ABC", "14.074", "FT8", "-10", "日本-东京", "2026-10-26", "2026-10-28"]`

*注：如果 QSL 还没寄出或还没收到，用空字符串 `""` 表示即可。代码内置了按时间自动倒序排序的功能，你只需要把新数据加在末尾即可。*

## 🚀 部署说明

本项目通过 GitHub Pages 进行托管。将代码推送至仓库，并在仓库的 `Settings -> Pages` 中选择对应的分支（如 `main`），保存后即可通过分配的域名直接访问。
